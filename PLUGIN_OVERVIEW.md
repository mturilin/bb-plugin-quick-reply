Review a long agent reply line by line instead of copying it into a message.

## What you get

- 👍, 👎 and 💬 on every paragraph, list item, table row and code block of an
  agent's reply, shown when you hover over it.
- A bar above the message box that counts your marks, with **Submit replies**
  to send them as one message.

## How it works

Your marks are kept in this BB window until you send them. When you send, the
agent gets an ordinary message from you that quotes each line you marked,
with your vote and comment under it. Lines you left alone are not mentioned.
The agent is not told about the plugin, and nothing leaves your machine apart
from that message.
